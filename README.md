# Preferred Power Washing — Premium Multi-Page Website

This version is intentionally **not** one long scrolling page.

## Pages
- `index.html` — premium brand / company homepage
- `residential.html` — residential-specific landing page
- `commercial.html` — commercial-specific landing page
- `pressure-washing.html` — pressure washing service landing page
- `window-cleaning.html` — window cleaning service landing page
- `landscaping.html` — landscaping service landing page
- `contact.html` — quote / lead capture page

## Brand System
Each landing page has a slightly different theme while staying consistent with the PPW identity:
- Residential: bright lime / curb-appeal theme
- Commercial: clean corporate lime / B2B theme
- Pressure washing: lime + aqua cleaning accents
- Window cleaning: cool glass / cyan accents
- Landscaping: green foliage accents

## Before Launch
Replace these placeholders in `contact.html`:
- YOUR PHONE NUMBER
- YOUR EMAIL ADDRESS
- YOUR CITY / SERVICE AREA

The quote form is a visual demo. Connect it to Formspree, Netlify Forms, your CRM, or booking platform.

## GitHub Pages
Upload all files/folders to the root of a GitHub repository, then enable GitHub Pages from the `main` branch.
